HLAKS WEB WONDERS - WEBSITE FILES

HOW TO PUBLISH (GitHub Pages)
1. Unzip this folder.
2. Upload index.html, home.html, about.html, our-work.html, contact.html and .nojekyll to the ROOT of your repository.
   (index.html must be at the top level, not inside a folder.)
3. Wait about a minute, then reload the site with Ctrl+F5.

Every page is self-contained: the styling, scripts, logo and Hlaluko's photo are built into each HTML file, so no css, js or images folders are needed.
The folder named source holds the editable CSS, JavaScript and your original pictures for reference only.
